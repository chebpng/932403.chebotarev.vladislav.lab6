# 932403.chebotarev.vladislav.lab6

Лабораторная работа №6. Введение в Node.js и базовый сервер на Express
Цель: освоить запуск Node.js-приложений, работу с модулями, создание простого
HTTP-сервера, а также превращение статического сайта в PWA (устанавливаемое
приложение с офлайн-режимом).

## Вариант 9

Тема «Каталог книг» (поиск и фильтрация). Маршруты: GET /, GET /about,
GET /api/books. Данные — массив книг (title, author, year). Query-параметры
`?author=` и `?year=` фильтруют список, без параметров отдаются все книги,
пустой результат — пустой массив.



## Запуск

```
npm install
npm start
```

## Маршруты

- `GET /` — каталог книг;
- `GET /about` — страница «О себе»;
- `GET /api/status` — JSON: статус, версия, uptime, число книг, список маршрутов;
- `GET /api/books` — все книги;
- `GET /api/books?author=Tolstoy` — фильтр по автору (регистр не важен,
  работают и русское написание, и латинская транслитерация: Толстой / Tolstoy);
- `GET /api/books?year=1869` — фильтр по году;
- `GET /api/books?author=Tolstoy&year=1869` — оба фильтра сразу;
- пустой результат — `[]` со статусом 200.
